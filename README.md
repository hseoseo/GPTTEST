# MindAR WebAR Builder

このリポジトリには MindAR を利用した WebAR 体験用のプロジェクト生成ツールが含まれています。ブラウザで `index.html` を開くだけで、マーカーごとに画像・動画・3D モデルを割り当てた WebAR プロジェクトを作成し、zip 形式でダウンロードできます。

## 使い方

1. MindAR CLI などで `.mind` 形式のターゲットファイルを準備します。複数マーカーを含むファイルにも対応しています。
2. このリポジトリを静的ホスティング環境に配置するか、ローカルで `index.html` をブラウザで開きます。
3. 画面上でターゲットファイルとマーカーごとの表示コンテンツ（画像・動画・glTF/GLB モデル）を登録します。
4. 「プロジェクトをダウンロード」ボタンを押すと、MindAR ランタイムと設定済みアセットを含む zip ファイルが生成されます。
5. 出力された zip を解凍し、生成された `index.html` をサーバーに配置すれば、そのまま WebAR 体験を公開できます。

## エクスポートされるファイル構成

- `index.html`: MindAR ランタイムを読み込み、登録したコンテンツを表示するエントリーポイント。
- `config.json`: ビルダーで登録したマーカーとアセットの対応関係、および変換パラメータ。
- `targets/targets.mind`: 指定した MindAR イメージターゲットファイル。
- `assets/`: 登録した画像・動画・3D モデルファイル。
- `references/`: 任意で登録したマーカーのリファレンス画像（ある場合のみ）。
- `README.md`: 生成されたプロジェクトの使い方をまとめたファイル。

## 動作要件

- 最新の Chromium ベースブラウザまたは Safari
- HTTPS 環境（カメラアクセスのため）
- MindAR がサポートするフォーマット（画像: PNG/JPEG、動画: MP4/WebM など、3D モデル: glTF/GLB）

## 開発

ローカルで UI を変更する場合は、任意の静的サーバー（例: `python -m http.server`）でルートディレクトリをホストしてください。
